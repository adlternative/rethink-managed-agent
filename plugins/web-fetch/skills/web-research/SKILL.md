---
name: web-research
description: How to research a question on the web with web_fetch. Use when the user asks you to look something up online.
---
1. Prefer primary sources (official docs, RFCs, the project's own repo) over aggregators.
2. Fetch at most three pages; quote the exact sentence that supports each claim.
3. End with a short "Sources" list of the URLs you actually fetched.
